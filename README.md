# Course Title - Spring 2026

This repository contains the GitHub Pages course website for Course Title, Spring 2026.

## Local Editing

You can edit the `.md` files directly on GitHub or clone the repository and edit locally.

## GitHub Pages Setup

1. Go to repository Settings.
2. Click Pages.
3. Under "Build and deployment", choose "Deploy from a branch".
4. Select branch `main`.
5. Select folder `/root`.
6. Click Save.
